Desarrollo y mantenimiento de soluciones ERP

Experiencia profesional

Actualmente trabajo en desarrollo y mantenimiento de soluciones ERP, participando en implementación de funcionalidades, análisis de incidencias y ajustes sobre sistemas empresariales.

Mi trabajo incluye desarrollo con Java y ADempiere, consultas y funciones PostgreSQL, lógica de negocio, procesos, callouts, Model Validators, reportería con JasperReports y mantenimiento de aplicaciones PHP/Laravel.

También participo en análisis y resolución de incidencias en ambientes DEV, QA y Producción.

Java ADempiere PostgreSQL SQL JasperReports PHP Laravel Git

Por tratarse de sistemas empresariales internos, no se publican código fuente, datos ni capturas de los ambientes profesionales.

Marketplace Full Stack

Aplicación web Full Stack desarrollada con frontend en React y backend utilizando Node.js y Express, conectada a una base de datos PostgreSQL.

El proyecto implementa registro e inicio de sesión de usuarios, autenticación mediante JWT, publicación de productos, favoritos y funcionalidades de mensajería.

Proyecto Backend / Web

Gestión de Salas de Atención

Aplicación web orientada a la administración de salas de atención, desarrollada utilizando Laravel y PostgreSQL.

El sistema permite trabajar con operaciones CRUD para registrar, consultar, modificar y eliminar información almacenada en la base de datos.

Este proyecto combina mi formación como desarrollador con mi conocimiento del área de Informática Biomédica.
